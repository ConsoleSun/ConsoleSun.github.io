发表于2026-08-02|技术
这不是一篇”Hello World”级别的 Agent 教程,而是一个真正跑在生产环境的外贸智能体系统的框架拆解。它同时服务外部客户(产品咨询、以图搜图)和内部员工(知识检索、邮件收发、客户挖掘、ERP 同步),并且已经实现了全自动获客。 一、为什么做这件事公司在做玻璃瓶制造与出口。外贸业务有两个很真实的痛点: 对客户——一个德国客户问”丘比特瓶子的规格是什么”,一个中东客户把酒瓶照片甩过来问”这个能做吗”。他们不想翻几十页的产品手册,就想有人能立刻答上来。 对员工——业务员要查报价、查工艺、查管理制度,发开发信、跟客户、把客户录进 ERP。信息散在四五个系统里,操作步骤繁琐,新人上手尤其慢。 我最初的想法很简单:能不能把这些全塞进一个对话框里? 客户和员工都只对着一个”人”说话,背后由 Agent 去查知识库、上网、发邮件、写 ERP。于是有了这个系统。 二、核心设计理念12Agent = LLM + 上下文 + 工具 = 大脑 + 眼睛 + 手脚 LLM 是大脑(推理决策),上下文是眼睛(它能看到什么),工具是手脚(它能做什么)。框架层的绝大多数工作,都是在打...
